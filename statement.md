# ChronoTrack: Terminal Routine Scheduler

## Problem Statement
Maintaining daily consistency requires adherence to time-bound routines. ChronoTrack provides a command-line interface (CLI) scheduling engine that monitors routine time slots, issues notifications, audits completion, and provides color-coded feedback on daily adherence.

## Scope of the Project
- Interactive creation, editing, and deletion of routine blocks.
- Time conflict validation preventing overlapping slots.
- Real-time routine tracking.
- Post-slot audit prompts to record tasks as completed or missed.
- ANSI-coded schedule display.
- Daily adherence metrics and summary reporting.

## Target Users
- Students and developers working in terminal environments who need simple, reliable time management without GUI overhead.

## High-Level Features
1. Routine Management: CRUD operations for routine blocks.
2. Execution Monitor: Clock polling against scheduled events.
3. Accountability Auditor: Post-slot status recording and performance tracking.
4. Terminal Dashboard: Color-formatted schedule display and daily summary metrics.s
